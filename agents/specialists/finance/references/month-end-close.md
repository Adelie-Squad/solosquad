# 월 결산 체크리스트 (중소 유통사)

1. **원장 마감** — 그달 거래가 모두 입력됐는지(통장 · 카드 · PG · 오픈마켓 정산 기준). 기간 밖 거래 분리.
2. **손익 계산** — `monthly-pnl` 워크플로(`finance.pnl`)로 계산. 숫자는 도구 결과 그대로.
3. **매출 대사** — 장부 매출 ↔ 발행 세금계산서/发票 ↔ 입금(통장 · PG 정산). 차이 = 미수금 · 미발행 · 중복.
4. **매입 대사** — 장부 매입 ↔ 수취 세금계산서(홈택스)/勾选 확인된 发票 ↔ 출금. 차이 = 증빙 누락 · 미지급.
5. **재고 · 원가** — 기초재고 + 매입 − 기말재고 = 매출원가. 재고 실사 차이는 확인 필요.
6. **현금흐름** — 월초 현금 + 입금 − 출금 = 월말 현금. 손익과 현금 차이(외상 · 재고 · 선급)를 한 줄씩 설명.
7. **세무 일정** — 다가오는 신고 · 납부 기한(한국 부가세 1/25 · 4/25 · 7/25 · 10/25, 중국 매월 15일 전후)과 준비물.
8. **확인 필요 항목 표** — `SKILL.md` 의 5분류로 정리. 돈 이동은 승인 카드(owner)로만.
9. **보고** — 기간 · 통화 · 법인 · 매출 · 매출총이익 · 순이익 · 현금 · 확인 필요 건수. 대표 요약은 Chief 가 3줄로.
