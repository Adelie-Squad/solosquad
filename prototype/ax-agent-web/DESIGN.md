## 색

공통 + 아래 변경

- **셸 배경** — 창 전체를 그라디언트 한 가지로 칠한다(배경색 전환 기능 없음).
  `135deg, #b9a7ff → #f6b8d6 → #ffd9b8`, accent 는 공통값 `#6d4aff` 그대로.

- 사이드바는 그라디언트 위에 직접 얹으므로 **반투명 흰색**만 쓴다: 기본 `rgba(255,255,255,.3)`,
  hover `.35–.5`, 선택 `.9`. 사이드바 글자색은 `#241c3f` (투명도로 보조 단계).
- 실시간 표시점: `#18c08f` + 퍼지는 링 애니메이션.
- 배경 값의 원천은 `src/data/dummy.ts` 의 `space` — 문서와 코드를 같이 고친다.

## 레이아웃

공통 대체

**Arc 브라우저 셸.** 창 전체 = 배경 그라디언트, 왼쪽 투명 사이드바, 오른쪽 흰 카드 한 장.

```
┌──────────────┬────────────────────────────────────┐
│ ← →          │                                    │
│ [하루에게…⌘K]│                                    │
│ [홈 ][메일 3]│         흰 카드 (radius 10)         │
│ [Task][스케줄]│         콘텐츠 max 980 / 홈 820     │
│ 🥐 사업장명   │                                    │
│ ● 실시간 작업 │                                    │
│   작업 행들…  │                                    │
│ + 새 요청     │                                    │
│            ⚙ │                                    │
└──────────────┴────────────────────────────────────┘
  264px          바깥 여백 8px (왼쪽은 사이드바가 붙음)
```

- 사이드바 폭 264px (860px 이하 220px). 카드 그림자 `0 8px 30px rgba(40,20,90,.16)` + 1px 헤어라인.
- **홈 하단 고정 입력부** — 홈은 카드 높이를 꽉 채우고, 인사·보고·대화 영역만 스크롤된다.
  추천 프롬프트 한 줄 + 입력창은 스크롤과 무관하게 카드 하단에 붙어 있다. 둘 다 콘텐츠 폭 820 으로 정렬.
- 랜딩(`/`)은 셸 밖 — 섹션 1개, 좌 카피 / 우 마스코트 2열, 860px 이하 1열.

## 문구

공통 + 아래 변경

- 화자는 **AI 직원 '하루'**, 사용자는 **"사장님"** 으로 부른다.
- 하루는 결과부터 말하고, 사장님이 할 일은 **한 가지 행동**으로 끝낸다. ("…승인만 하시면 돼요.")
- 자동으로 처리한 일과 승인이 필요한 일을 항상 구분해 말한다 — 신뢰의 핵심.
