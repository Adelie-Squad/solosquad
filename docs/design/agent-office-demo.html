SoloSquad 툰 오피스

펭귄 에이전트 3명이 각자 책상에서 일합니다. 자리 이동 없이 상태에 따라 제자리 모션만 바뀝니다. 블록은 키캡처럼 둥근 테두리와 테이퍼를 넣었고, 잉크선은 바깥 윤곽은 굵게, 안쪽 모서리는 얇게 두 단계로 긋습니다.

3D 장면을 불러오지 못했습니다. 페이지를 새로고침해 주세요.

스타일 요소

상태 파일 이벤트

    이벤트는 예시 시뮬레이션입니다. 실제로는 SoloSquad의 state 파일 변경이 이 자리에 들어옵니다.

    이 룩으로 만드는 순서

    01

    팔레트를 레퍼런스에서 그대로 뽑는다

    오피스 색은 키캡 도시 이미지에서, 볼 색은 펭귄 키링에서 픽셀을 찍어 뽑았습니다. 오브젝트마다 윗면/왼면/오른면 3색을 한 세트로 정해 두면 새 오브젝트를 추가해도 톤이 흐트러지지 않습니다.

    • 바닥#D0C5A7
    • 윗면#E1DBC5
    • 왼면#F0EDE8
    • 오른면#7E6E3B
    • 라임#9AC22D
    • 파랑#2C74E0
    • 볼 마젠타#E01FAE
    • 잉크#111008

    지정한 hex가 화면에 그대로 찍히도록 three.js 색 관리를 끕니다(ColorManagement.enabled = false, 출력 색공간 Linear).

    02

    빛 계산 대신 면 방향으로 색을 칠한다

    법선이 위를 보면 윗면색, 카메라 기준 오른쪽(+x)을 보면 오른면색, 나머지는 왼면색입니다. 펭귄처럼 둥근 형태도 같은 규칙으로 색 띠가 나뉩니다. 타원체는 scale을 비균일하게 쓰므로 법선은 normal matrix로 변환해야 띠가 어긋나지 않습니다.

    // vertex: 비균일 scale에도 맞는 월드 법선
vN = normalize(transpose(inverse(mat3(modelMatrix))) * normal);

// fragment
float right = smoothstep(-0.08, 0.08, n.x - n.z);
float top   = smoothstep(0.55, 0.65, n.y);
vec3 c = mix(mix(uLit, uShade, right), uTop, top);
    03

    블록은 둥근 사각형을 베벨로 뽑고 위를 좁힌다

    레퍼런스 키캡의 인상은 둥근 모서리, 윗면 테두리, 위로 좁아지는 옆면 세 가지에서 나옵니다. ExtrudeGeometry로 둥근 사각형을 뽑고, 베벨을 2단으로 주면 윗면 테두리에 잉크선이 정확히 한 줄 생깁니다. 마지막에 높이에 비례해 x·z를 줄이면 테이퍼가 됩니다.

    const g = new THREE.ExtrudeGeometry(roundedRect(w, d, r), {
  depth: h - 2 * bev, bevelEnabled: true,
  bevelThickness: bev, bevelSize: bev,
  bevelSegments: 2,   // 22.5°, 67.5° 두 면 → 가운데에 선 한 줄
  curveSegments: 8    // 모서리 곡선은 11°씩 → 선 없이 매끈
})
g.rotateX(-Math.PI / 2)
// 높이 t(0~1)에 비례해 위쪽 정점을 안으로
p.setX(i, x * (1 - t * 2 * inset / w))
    04

    잉크선은 두 가지 굵기로 긋는다

    장면을 색·깊이 한 번, 법선 한 번 그린 뒤 화면에서 선을 찾습니다. 깊이가 크게 바뀌는 곳은 바깥 윤곽이라 굵게, 법선만 꺾이는 곳은 안쪽 모서리라 얇게 칠합니다. 레퍼런스의 펜 선 위계가 이 차이에서 나옵니다.

    for (int i = 0; i < 8; i++) {
  vec2 d = dirs[i] * uTexel;
  sil   = max(sil,   step(0.18, abs(depth(vUv + d * uThick) - dc)));
  crease = max(crease, step(0.25, 1.0 - dot(normal(vUv + d * uThick * 0.5), nc)));
}
gl_FragColor = vec4(mix(color, uInk, max(sil, crease)), 1.0);
    05

    펭귄 에이전트를 부품으로 조립한다

    키링처럼 납작하고 통통한 봉제 인형 실루엣이 목표입니다. 얼굴은 별도 메시를 붙이지 않고 몸통 셰이더 안에서 하트 모양 영역을 흰색으로 칠합니다. 메시를 겹치면 경계마다 선이 생겨 눈이 흰자 위 동공처럼 보이기 때문입니다. 셰이더로 그리면 테두리 잉크선과 안쪽 스티치 점선까지 깔끔하게 넣을 수 있습니다.

    부품만드는 법
    몸통LatheGeometry로 서양배 단면을 돌리고 앞뒤를 0.74배로 눌러 납작하게
    얼굴 패널타원 1개 + 원 2개의 거리장(SDF) 합집합. 두 원 사이로 검은 몸이 V자로 내려와 하트 얼굴이 됨. 경계 0에 잉크선, -0.036에 스티치 점선
    눈 · 볼몸 표면에 반쯤 묻힌 세로 타원 눈, 바깥 아래에 마젠타 볼. 눈은 주기적으로 깜빡임
    부리납작한 팔면체. 가운데 꺾임에 선이 생겨 입 모양이 됨
    날개어깨 피벗 그룹 아래 납작한 타원. 피벗 회전만으로 손 흔들기, 타이핑

    에이전트마다 소품 하나로 구분합니다. 기획 PM은 파란 나비넥타이, 리서처는 동그란 안경, 검증관은 날개에 든 돋보기입니다. 소품은 같은 부품 함수에 붙였다 뗄 수 있어서 에이전트를 늘려도 몸은 공유합니다.

    06

    상태는 제자리 모션으로 보여 준다

    에이전트 코드는 건드리지 않습니다. Node 서버가 state/*.json을 감시하다가 WebSocket으로 보내면, 캐릭터는 자리를 지키고 모션만 바꿉니다. 모션 값은 목표값으로 부드럽게 보간해서 상태가 바뀌어도 튀지 않습니다.

    SoloSquad 이벤트상태제자리 모션
    파일 작성, 도구 호출typing앞으로 살짝 숙이고 양 날개로 번갈아 타자
    추론 중, 응답 대기thinking몸을 좌우로 천천히 기울이고 눈이 위를 봄
    사람 승인 필요waiting한쪽 날개를 높이 들고 흔들며 작게 콩콩
    작업 완료done양 날개를 들고 점프, 착지할 때 찌그러짐
    07

    영상 프리토타입은 Blender로 같은 룩을 낸다

    • 면 톤: Geometry 노드의 Normal을 Separate XYZ로 나눠 Color Ramp(Constant)에 넣고 Emission으로 출력합니다.
    • 잉크선: Freestyle에서 Silhouette은 굵게, Crease는 얇게 두 개의 Line Set으로 나눕니다.
    • 그림자: Shadow Catcher 바닥과 각도 0에 가까운 Sun 라이트 하나로 가장자리를 딱 끊습니다.
