## 1. 이 마이너가 만족해야 할 것 — "회사"의 엔진 조건

1. **여러 과제가 동시에 돈다** — 과제마다 swarm 하나, 과제끼리는 병렬 (결정 19 · 23)
2. **꺼졌다 켜져도 이어서 한다** — checkpointer + 운영 층의 자동 재개 (M24)
3. **정해진 시각에 스스로 일을 만든다** — cron · goal 이 과제를 생성 (M24)
4. **한 계정이 막혀도 멈추지 않는다** — 활성 풀 안에서 다른 연결로 폴백 (결정 22 · M25)
5. **사람 승인이 필요한 곳에서 멈추고 기다린다** — interrupt (결정 19). v2.0 에서는 CLI 로 승인, 웹 승인은 v2.1.0
6. **에이전시 업데이트가 고객사 커스텀을 지우지 않는 구조** — core(엔진 · 도구 + 오너) → org → workspace 3층과 엔진 커스텀 확장점을 처음부터 (결정 40). 업데이트 흐름 자체는 v2.3.0

## 2. 아키텍처 (v2.0.0 이 세우는 층)

```
 표면       solosquad chat (CLI)  ── JSON 경계(결정 10) ──  [v2.1.0] 웹
 운영 층    run manager — threads · runs · crons · store             (M24, LangGraph Server 모양)
 그래프     LangGraph 모방(자체 재구현) + swarm 층                      (결정 19 · 20 · 23)
            Chief = default_active_agent ⇄ 부서 에이전트들 (handoff = Command)
 라우팅     연결 → 풀 → 라우팅 — 모델 고르기 ⟂ 연결 고르기 · 정책 = Chief (결정 22 · 35)
 하네스     claude-code · opencode(API 키 전반) · codex · lite           (결정 24 · M21)
 도구       MCP — handoff 도구 · 시크릿 · 사용자 MCP   ([v2.2.0] 브라우저)
 저장       sqlite3 — checkpoint · store · 세션 · 가계부(토큰 · 비용)    (M26)
 층 구분    엔진(교체 가능) │ core/custom · owner │ orgs/<org>/ │ workspaces/<사무실>/   (결정 40)
```

**동시성 (결정 23)** — 운영 층 · 엔진 · 하네스가 하나의 `asyncio` 이벤트 루프에서 돈다. 동기 얼굴은 CLI · 테스트용 포장. 로더 · 파서 · 검증은 동기 함수.
**격리** — 과제마다 git worktree(§D3).

### [3] 실행 — 결정 블로커 없음 ✅ (M21 · M24 = 결정 34 · 라우팅 정책 = 결정 35)
- 그래프 엔진 — Pregel super-step · `Command`/`Send` · `interrupt`/`resume` · durability 3값 · 동기/비동기 노드
- swarm 층 — `create_swarm` · handoff 도구(MCP) · `active_agent` · `default_active_agent` = Chief · 간선 선언(M22)
- **노드 ↔ 하네스**(결정 34) — 상태가 유일한 진실. 에이전트가 활성화될 때마다 새 CLI 세션을 열고 상태에서 이력을 주입한다. handoff = MCP 도구 → `Command(goto=…)`. CLI resume 은 추후 캐시
- **운영 층**(결정 34) — LangGraph Server 모양: assistant(회사 설정) · thread(과제) · run(실행) · cron. 재시작 시 `running` 이던 run 자동 재개 · durability 기본 `sync`
- **연결 풀 · 라우팅 = Chief 관리**(결정 35) — Chief 가 연결별 예산 · 한도 · 동시 슬롯 · 에이전트별 모델 선호 정책을 소유한다. 호출 단위 선택은 그 정책을 규칙으로 실행하고, **한도 소진 · 예산 경고 · 애매한 판정은 Chief 에게 올라간다**. 한도 추적 기본값: 구독 = CLI rate-limit 신호, API = 429 · 응답 헤더, 연결별 월 예산
- §D3 worktree + 85% 자동 교대 · §D4 가드 · 훅 단일 명세
- **AC (골든):** Given LangGraph 원본과 같은 그래프 · 입력 / When 자체 엔진 실행 / Then 상태 전이 · `stream_mode="updates"` 시퀀스 동일(원본 = 테스트 전용 dev 의존)
- **AC (회사):** Given 활성 연결 2개 · 동시 과제 5개 / When 연결 1개 한도 초과 / Then 진행 중 과제가 다른 연결로 이어져 개입 없이 5개 모두 완주
