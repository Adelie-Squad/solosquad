## 4. 인수 조건

- Given 새 컴퓨터 / When `curl … | sh`(또는 `irm … | iex`) / Then Python 사전 설치 없이 설치되고 해시가 다르면 중단된다
- Given 에이전시가 새 코어를 릴리스 / When 고객사 FDE 가 받음 / Then 그 고객사 기준 설명과 적용 · 보류 · 건너뛰기가 웹에 뜨고, 사용자가 고르기 전에는 코어가 바뀌지 않는다
- Given org 에 커스텀 스킬 2개 · `core/custom/hooks/` 훅 1개 / When 코어 업데이트 적용 / Then 커스텀이 그대로 동작하고, 회귀 점검이 실패하면 직전 엔진으로 자동 복귀한다
- Given 같은 컴퓨터의 고객사 A 는 적용 · B 는 보류 / When 둘 다 구동 / Then A 는 새 엔진, B 는 이전 엔진으로 돈다
- Given 셀프 사용자가 측정에 동의하지 않음 / When 24시간 구동 / Then 에이전시로 나가는 요청 0건
- Given 관리형 설치본 3곳 / When 에이전시 화면 / Then 상태 · 코어 버전 · 최근 오류가 가명 ID 로 보이고 고객사 이름은 에이전시 어디에도 없다
- Given 고객사 FDE 의 승격 후보 / When 전송 / Then 후보에 고객사 정보가 없고 에이전시 FDE 의 판단이 채널로 돌아온다
- Given 고객사 FDE 의 자유 텍스트 질문 / When 전송 / Then 비식별 필터와 사장님 확인을 거친 내용만 나가고 *나간 내역* 에 남는다

## 5. 구현 방법

> R9 — 착수 시 담당 에이전트 리뷰로 확정. 지금은 방향 · 대안까지.

### 5.1 아키텍처 · 구조 (system-architect)
```
 에이전시                                         고객사 머신(설치본마다)
 GitHub Releases(코어 · org 패키지 · 해시)  ──▶   설치기 → ~/.solosquad/engines/<버전>/
 설치 스크립트 도메인(버전 핀)                      인스턴스 ─ 업데이트 확인 → FDE 설명 → 사용자 결정
 수신 서버(Workers + D1, A3)  ◀── 가명 요약 · 후보 · 메시지 ──  나간 내역(웹)
 에이전시 FDE · 관할 화면 ── PR ──▶ SoloSquad 저장소 / org 패키지 저장소
```
- 방향은 **에이전시 → 고객사가 기본**(결정 30). 고객사 → 에이전시는 동의된 가명 데이터뿐.

### 5.2 설계
- **설치기** — 셸/PowerShell 스크립트: uv 설치 → 압축본 다운로드 · SHA-256 검증 → 엔진 보관소 배치 → `solosquad` 런처 등록. "파일로 받아 확인 후 실행" 경로 병기.
- **엔진 버전 런처** — `solosquad` 는 리포의 `core/engine.lock` 을 읽어 해당 버전 엔진으로 실행. `prune` 은 어떤 리포도 안 쓰는 버전만 삭제.
- **업데이트** — 새 엔진을 옆에 설치 → 고객사 리포 사본에서 회귀 점검(파서 · 확장점 로딩 · 패치 기준 버전 · 스모크) → 통과 시 lock 교체 · 실패 시 유지.
- **텔레메트리** — 하루 1회 요약 + 오류 발생 시 즉시. 전송 전 로컬 *나간 내역* 에 먼저 기록 → 전송.

### 5.3 데이터 (data-engineer)
- 에이전시 D1: installs(가명 ID · 코어 버전 · 마지막 heartbeat) · usage_daily(가명 ID · 날짜 · 횟수 · 토큰 · 비용 합계) · errors(가명 ID · 유형 · 횟수) · candidates · messages. 보관 12개월 후 삭제.
- 가명 ID = 설치 시 난수 생성(고객 + org 2단). 대응표는 창업자의 고객사 관리 리포에만(결정 38).

### 5.4 보안 · 권한 (security)
- 공급망: 버전 핀 + 해시 · 서명(가능하면 Sigstore) · 스크립트 도메인 HSTS.
- 수신 서버: 설치본별 발급 토큰 · 요청 크기 상한 · 받는 쪽 비식별 재검사.

### 5.5 작업 분할 · 담당
| 작업 | 담당 |
|---|---|

| CI 배포물 · 해시 · 릴리스 노트 | infra |

| 텔레메트리 · 나간 내역 · 비식별 필터 | data-engineer · security |
