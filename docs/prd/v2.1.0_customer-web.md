**JSON 경계(결정 10)** — 웹은 코어 ↔ 표면 계약의 이벤트(stream_mode 7종 직렬화)와 운영 층 API(threads · runs · crons)만 쓴다. **코어를 고치지 않고 웹이 붙는 것**이 이 마이너의 구조 검증이다.

## 2. AC

- Given 팀 3개(재무 · 소싱 · 마케팅) / When 사무실 화면 / Then 각 팀에 소속된 에이전트와 지금 하는 과제가 팀별로 보인다 *(사람 사용자 권한 AC 는 결정 36 정렬 후 추가)*
- Given 진행 중 과제가 interrupt 로 멈춤 / When 사장님이 웹에서 승인 / Then 과제가 그 지점부터 이어지고 승인자 · 시각이 기록된다
- Given 자리를 비운 8시간 동안 과제 3개 완료 / When 접속 / Then 첫 화면에 3개의 보고와 비용 합계가 보인다
- Given 웹 서버 프로세스 재시작 / When 다시 접속 / Then 진행 중이던 과제 · 대화 세션이 그대로다(상태는 코어 checkpoint 에 있다)
- Given 사설망에 들어온 휴대폰 / When 접속 / Then 로그인을 거쳐야만 들어갈 수 있고, 공개 터널이 꺼져 있으면 사설망 밖에서는 서버가 보이지 않는다
- Given 연결 1개의 월 예산 80% 도달 / When Chief 가 감지 / Then 웹에 Chief 의 경고와 제안(다른 연결로 돌리기 · 예산 올리기)이 뜬다

## 4. 리스크

- **🔴 로컬 서버를 밖에 여는 보안** — 공개 터널은 인터넷에 노출된다. → **기본 = 사설망** · 공개 터널은 옵트인 · 로그인 필수 · 세션 만료(결정 34).
- **🟡 프로토타입 ↔ 정식 간극** — 더미 데이터 기반 화면을 실제 이벤트에 하나씩 결선. 결선 안 된 화면은 출시하지 않는다.
- **🟡 두 언어** — 웹은 TS(결정 9). 경계는 JSON 계약 한 곳(결정 10). 스키마는 코어가 단일 출처.
