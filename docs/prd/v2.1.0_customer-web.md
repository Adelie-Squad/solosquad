## 1. 목표

- **major(v2.x):** roadmap §2.6 — *"SoloSquad 는 솔로프러너 · 소규모 비즈니스에게 에이전트 회사를 맞춤형 AX 솔루션으로 제공하는 에이전시"*.
- **minor(2.1.0):** **"사장님이 웹에 로그인해 회사에 일을 맡기고, 지켜보고, 승인하고, 보고받는다 — 실제로 작동하는 AI 기능과 함께."**
- **이 버전이 맡는 조각:** v2.0.0 엔진 위에 고객사 웹 표면(로그인 · 승인 · 보고)을 얹어 관리형 파일럿의 시작점을 만든다(결정 33 — 순서 기준 = 관리형 파일럿을 가장 빨리 시작할 수 있는 순서).
- **이 버전이 끝나면** 관리형 PoC 를 시작할 수 있다: 창업자가 로컬에서 고객사 솔루션을 작업 → 프라이빗 git → Cloudflare 로 배포 → 고객사는 웹 로그인(결정 39). 사람 FDE 가 3개월 커스텀을 시작할 수 있는 상태.

### 3.4 인수 조건

```
C1  Given  고객사 A · B 가 각자 배포됨
    When   A 계정으로 로그인
    Then   A 의 회사만 보이고 B 의 도메인 · 데이터에는 A 계정으로 접근할 수 없다

C2  Given  로그인하지 않은 방문자
    When   고객사 도메인 접속
    Then   로그인 화면 외에는 어떤 API 도 응답하지 않는다

C3  Given  org 2개(테슬라 · 스페이스X) 계정을 둘 다 가진 사람
    When   계정 전환
    Then   전환한 org 의 사무실만 보인다

C4  Given  내부망 유형 사무실
    When   사내망 밖에서 접속
    Then   로그인이 맞아도 사무실 검증에서 막히고 *사내망에서만 열립니다* 안내가 뜬다

C5  Given  팀 3개(재무 · 소싱 · 마케팅)
    When   사무실 화면
    Then   팀마다 소속 에이전트와 지금 하는 과제가 보인다

C6  Given  과제가 승인 대기로 멈춤
    When   사장님이 웹에서 승인
    Then   그 지점부터 이어지고 승인자 · 시각이 기록된다

C7  Given  자리를 비운 8시간 동안 과제 3개 완료
    When   접속
    Then   첫 화면에 3개의 보고와 비용 합계가 보인다

C8  Given  실행 정책이 `외부 API 금지` 인 사무실
    When   라우팅
    Then   외부 API 키가 있어도 사내 · 로컬 모델로만 간다

C9  Given  연결 1개 월 예산 80%
    When   Chief 가 감지
    Then   웹에 경고와 제안(다른 연결 · 예산 조정)이 뜬다

C10 Given  창업자가 고객사 솔루션 리포에 push 후 재배포
    When   인스턴스 재시작
    Then   진행 중 과제는 이어지고 데이터 폴더는 유지된다

C11 Given  웹 서버 재시작
    When   다시 접속
    Then   로그인 세션은 만료 전까지 유지되고 대화 · 과제가 그대로다
```

- 사람 사용자 권한(W7) 인수 조건은 프로토타입 정렬 후 새 ID 로 추가한다(기존 ID 재사용 금지, K1).

## 4. 구현 방법

### 4.1 아키텍처 · 구조 (system-architect)

```
 브라우저 ──https──▶ Cloudflare (Access: 이메일 OTP · 허용 목록)
                         │ Tunnel (고객사별 호스트명 → localhost 포트)
                         ▼
 창업자 상시 머신 ─ 인스턴스(사무실 1개) ───────────────────────────────
   ASGI 앱 (Starlette · uvicorn, W2 · I5)
     /            → web/ 빌드 정적 파일 (W5 · I2: 같은 origin)
     /api/*       → 인증 미들웨어(세션 쿠키) → 기존 운영 층 API 를 감싼 라우터
     /api/events  → SSE (사무실 · 과제 · 승인 실시간)
   RunManager · 회사 그래프 · 라우터 (v2.0.0 그대로)
   데이터 폴더: org/accounts.sqlite (W6 · I15) · 사무실/state · runs · ledger · secrets
```
