> **상태:** 초안 (2026-10-28, rev1 — 결정 33 분할로 신설) · **성격:** [개발] 웹 표면 + 코어 ↔ 표면 JSON 경계의 첫 외부 소비자 · **착수 0%.**
> **정본:** ideation `260803-*` **§0.0(결정 1~33)** · 미결 = §0.0.7. **v2.x 목표:** roadmap §2.6. **선행:** [v2.0.0](v2.0.0_orchestration-and-harness-platform.md) 엔진 코어.
> **화면 · 흐름의 입력:** `prototype/ax-agent-web`(브랜치 `feat/prototype-ax-agent-web` — 'AI 직원 하루', 가설 H1~H10). 착수 시 그 PRD 를 이 문서로 흡수한다.
> **용어 (결정 36):** 프로토타입의 *마스터* = **Chief** · *부서* = **팀** · *부서 권한 팀원* = **팀 소속 에이전트**. 프로토타입 정렬은 사용자가 2.0.x 동안 하고, 그때 사람 사용자 권한(M31 ①)을 재확인한다.
> ⚠️ 번호 이력: 이 번호의 이전 문서(클라우드 + 메신저)는 결정 33 으로 [v2.4.0](v2.4.0_docker-cloud-deploy-and-health-notify.md) 으로 옮겨졌다.

## 소속 목표 (R1)

- **major(v2.x):** roadmap §2.6.
- **minor(2.1.0) 목표:** **"사장님이 웹에 로그인해 회사에 일을 맡기고, 지켜보고, 승인하고, 보고받는다 — 실제로 작동하는 AI 기능과 함께."** 이 마이너가 끝나면 **관리형 PoC 를 시작**할 수 있다.
- **PoC 공급 방식 (결정 39):** 창업자가 로컬에서 고객사 솔루션을 작업 → **고객사 솔루션 프라이빗 git 리포**에 push → **Cloudflare 로 배포** → 고객사는 그 웹에 접속 · 로그인. 고객사 쪽 설치는 없다. FDE 에이전트(v2.2.0) 없이 사람 FDE 가 3개월 커스텀을 시작할 수 있는 상태가 목표.

**JSON 경계(결정 10)** — 웹은 코어 ↔ 표면 계약의 이벤트(stream_mode 7종 직렬화)와 운영 층 API(threads · runs · crons)만 쓴다. **코어를 고치지 않고 웹이 붙는 것**이 이 마이너의 구조 검증이다.

## 2. AC

- Given 팀 3개(재무 · 소싱 · 마케팅) / When 사무실 화면 / Then 각 팀에 소속된 에이전트와 지금 하는 과제가 팀별로 보인다 *(사람 사용자 권한 AC 는 결정 36 정렬 후 추가)*
- Given 진행 중 과제가 interrupt 로 멈춤 / When 사장님이 웹에서 승인 / Then 과제가 그 지점부터 이어지고 승인자 · 시각이 기록된다
- Given 자리를 비운 8시간 동안 과제 3개 완료 / When 접속 / Then 첫 화면에 3개의 보고와 비용 합계가 보인다
- Given 웹 서버 프로세스 재시작 / When 다시 접속 / Then 진행 중이던 과제 · 대화 세션이 그대로다(상태는 코어 checkpoint 에 있다)
- Given 고객사 A · B 가 각자 배포됨 / When A 계정으로 로그인 / Then A 의 회사만 보이고, B 의 도메인 · 데이터에는 A 계정으로 접근할 수 없다
- Given 로그인하지 않은 방문자 / When 고객사 도메인 접속 / Then 로그인 화면 외에는 아무 API 도 응답하지 않는다
- Given 창업자가 고객사 솔루션 리포에 push / When 배포 / Then 진행 중인 과제는 checkpoint 에서 이어지고 고객사 데이터 폴더는 유지된다
- Given 연결 1개의 월 예산 80% 도달 / When Chief 가 감지 / Then 웹에 Chief 의 경고와 제안(다른 연결로 돌리기 · 예산 올리기)이 뜬다

## 4. 리스크

- **🔴 인터넷 공개 서버** — PoC 는 처음부터 인터넷에 열려 있다. → 로그인 필수 · 세션 만료 · 앞단 게이트(M33) · 로그인 전 API 무응답 · 고객사별 인스턴스 · 데이터 분리.
- **🔴 창업자 머신 의존** — 권장 구성(M33 ⓐ)에서는 엔진이 창업자의 상시 머신에 있다. → OS 서비스 구동 · 재부팅 자동 기동(v2.0) · 꺼짐 감지는 우선 Cloudflare 측 상태 확인으로, 알림은 v2.4.0.
- **🟡 프로토타입 ↔ 정식 간극** — 더미 데이터 기반 화면을 실제 이벤트에 하나씩 결선. 결선 안 된 화면은 출시하지 않는다.
- **🟡 두 언어** — 웹은 TS(결정 9). 경계는 JSON 계약 한 곳(결정 10). 스키마는 코어가 단일 출처.
