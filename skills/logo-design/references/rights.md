# 상표 조사 · AI 출력의 권리 (SoloSquad 작성 — 법률 자문이 아니다)

## 1. 상표 조사는 사용자가(또는 변리사가) 한다
에이전트는 상표 등록 가능성을 보장할 수 없다. 콘셉트를 고르기 전·출원 전에 아래를 권한다. 결과 판단은 변리사.

| 어디 | 무엇 |
|---|---|
| **KIPRIS** (kipris.or.kr, 특허청) | 한국 — 문자 상표(한글·로마자 표기 모두)와 도형 상표(도형 분류 코드)로 검색 |
| **USPTO** (Trademark Search) | 미국 — 문자 상표, 디자인 코드 검색 |
| WIPO Global Brand Database | 여러 나라 한 번에 (해외 진출 계획이 있을 때) |
| 역이미지 검색 | 비슷한 도형이 이미 쓰이는지 |

- **니스 분류**: 소프트웨어·AI 회사의 기본은 **9류**(소프트웨어·앱), **35류**(경영 컨설팅·광고·사업 지원), **42류**(SaaS·IT 컨설팅·소프트웨어 개발).
  교육 서비스가 있으면 41류도. 실제 지정 상품·서비스는 사업 범위를 보고 변리사와 정한다.
- 이름(문자)과 로고(도형)는 따로 검색하고 따로 출원할 수 있다. 로마자 표기를 여러 개 쓰면 각각 검색한다.
- 도메인·SNS 핸들·사업자 상호 중복도 같이 본다(상표와 별개).
- 에이전트는 검색어 목록(한글·로마자·비슷한 발음)과 분류 후보를 표로 만들어 넘기는 데까지 한다. "등록 가능합니다" 라고 말하지 않는다.

## 2. AI 가 만든 그림의 권리
- 여러 나라(미국 저작권청 지침 등)에서 사람의 창작적 기여 없이 AI 가 만든 부분은 저작권 보호를 받기 어렵다고 본다. 상표는 사용·등록으로 보호되지만,
  **저작권까지 확실히 하려면 최종본은 사람이 다듬은 벡터**여야 한다.
- 그래서 이 skill 의 산출물은 **탐색 시안**이다. 확정 단계에서 사람(대표 또는 디자이너)이 형태·비례·글자를 직접 고치고, 그 과정(버전 파일·결정 기록)을 남긴다.
- 유료 이미지 생성 AI(텍스트→이미지)는 쓰지 않는다: 학습 데이터 출처가 불분명하고 기존 로고와 닮을 위험이 크며, 결과가 벡터가 아니다.
  이 skill 은 코드로 기하 도형을 그린다.
- 기존 로고를 따라 그리거나 "○○ 로고처럼" 의 형태를 옮기지 않는다. 참조는 **태도·구조 설명**(예: "심볼만으로도 쓰는 사과 같은 단독 심볼 체계")까지.

## 3. 인수인계에 적을 것
사용 글꼴과 라이선스 · AI 보조 범위(시안 탐색)와 사람이 고친 범위 · 권한 상표 조사 목록 · 확인하지 못한 것.
