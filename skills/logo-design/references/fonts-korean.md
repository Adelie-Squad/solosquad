# 글꼴 — OFL 서체와 한글 워드마크 (SoloSquad 작성)

## 1. 쓸 수 있는 글꼴 (SIL Open Font License 1.1)
OFL 은 로고에 써도 되고, 글자를 외곽선(경로)으로 바꾼 로고는 "글꼴 소프트웨어"가 아니라 그림이 되므로 재배포 조건이 붙지 않는다.
글꼴 파일 자체를 팔거나, 수정한 글꼴을 원래 이름(Reserved Font Name)으로 배포하는 것만 안 된다. 쓴 글꼴·버전·라이선스는 인수인계에 적는다.

| 글꼴 | 문자 | 성격 | 메모 |
|---|---|---|---|
| **Pretendard** | 한글 · 라틴 | 중립 고딕, 9 굵기, 가변 | Inter 기반 라틴 + 본고딕 계열 한글. 국내 UI 기본값 — 그만큼 흔하다 |
| **Wanted Sans** | 한글 · 라틴 | 기하적, 조금 넓은 비례 | 숫자·라틴이 단단하다. 스타트업 톤 |
| **SUIT** | 한글 · 라틴 | 둥근 기하 고딕, 가변 | 획 끝이 부드럽다. 친근한 톤 |
| **Inter** | 라틴 | 뉴 그로테스크, 가변 · opsz | 라틴 워드마크 · 브랜드 본문 |
| **Noto Sans KR** | 한글 · 라틴 | 본고딕 계열 | 가장 넓은 지원, 기본기 |
| **Noto Sans SC** | 간체 중국어 | 본고딕 계열 | zh-CN 자료가 있을 때 |

- 받는 곳은 각 글꼴의 공식 저장소/Google Fonts. 사용자가 이미 설치한 글꼴인지 먼저 확인하고, 설치는 사용자 확인 후.
- 상업 글꼴(산돌·윤디자인 등)은 "로고 사용(BI/CI)" 이 별도 라이선스인 경우가 많다 — 권하지 않는다. 사용자가 원하면 약관 확인을 요청한다.
- 무료라도 OFL 이 아닌 글꼴(개인 무료, 상업 금지 등)은 로고에 쓰지 않는다.

## 2. 로고 글자는 직접 그린다
- 기본: 글꼴을 그대로 치지 않는다. 글꼴은 **비례·굵기의 출발점**이고, 로고 글자는 코드로 그리거나(기하 프리미티브) 외곽선을 딴 뒤 고친다
  (`typography.md` §3 단계 2–4). 그대로 친 글꼴은 누구나 똑같이 칠 수 있어 소유감과 보호가 약하다.
- 브랜드 서체(본문·웹)는 위 OFL 글꼴 중 1–2 개로 정하고, 로고 글자의 특징(획 끝 각도·모서리 반경)을 서체 선택 기준으로 쓴다.

## 3. 한글 워드마크 메모
- **모아쓰기**: 한글 한 글자는 초성·중성(·종성)이 네모 안에 모인다. 자모 비례는 글자마다 다르다
  — `제`(ㅈ+ㅔ, 받침 없음)와 `슬`(ㅅ+ㅡ+ㄹ, 받침 있음)은 초성 높이가 다르다. 같은 높이로 맞추면 `슬` 이 답답하다.
- **네모틀 vs 탈네모틀**: 네모틀(본고딕류)은 안정·공적, 탈네모틀(초성·중성·종성 기준선을 맞춘 글꼴)은 개성·현대적. 로고에서는
  탈네모틀이 기하적 통일을 만들기 쉽다.
- **획 대비**: 한글 가로획은 세로획보다 5–10 % 얇게 해야 같은 굵기로 보인다(라틴보다 가로획이 많다). 작은 크기에서 ㅔ·ㅡ 사이 틈이 막히지 않게
  최소 틈 ≥ 캔버스 높이의 1/24.
- **ㅇ · 원형 자모의 오버슈트**: 원형 자모는 위아래로 1–3 % 넘쳐야 같은 높이로 보인다.
- **라틴과 함께 쓸 때**: 한글 글자 높이는 라틴 대문자 높이보다 5–10 % 크게 잡아야 시각적으로 같다(한글은 네모 안에서 비어 보인다).
  굵기도 한글 쪽을 한 단계 가볍게 해야 회색도가 맞는다.
- **로마자 표기**: 국립국어원 로마자 표기법(2000)이 기본이다(제슬 → Jeseul). 짧은 상표형 표기(JESL 등)는 발음이 흔들릴 수 있으니
  장단점을 표로 비교해 사용자에게 고르게 한다. 도메인·SNS 핸들·상표 조사는 표기마다 따로 한다.
- **자모 기반 심볼**: 자모(ㅈ·ㅅ·ㄹ…)를 심볼로 쓰면 한국어 화자에게는 바로 읽히고 외국인에게는 추상 도형으로 읽힌다 — 두 독해가 모두 괜찮은지 확인한다.
- **좌우 반전 테스트**: ㄹ·ㅈ 처럼 방향이 있는 자모는 거울상이 다른 글자/기호로 읽히지 않는지 본다.

## 4. 중국어(zh-CN)
간체 표기가 필요하면 별도 확인: 음역 한자 선택은 뜻이 따라오므로 사용자(또는 원어민) 승인 없이 정하지 않는다. 글꼴은 Noto Sans SC.
